## Нові неархівовані рішення

### 2026-10-21 — Parakeet V3 замість MacWhisper
Вибрано `mlx-community/parakeet-tdt-0.6b-v3` через `parakeet-mlx` (уже встановлено,
модель у HF-кеші). Одна модель покриває uk/en/ru → проба whisper-small і
роутинг мов з `transcribe-and-post.sh` зникають. Програли: MacWhisper `mw`
(платний, IPC через сокет запущеного GUI-застосунку), whisper-large-v3-turbo
через mlx_whisper (повільніший, галюцинує на тиші; fallback-кандидат).

### 2026-10-21 — Без VPS
Усі кроки після запису — plain API-виклики або локальна робота; єдине, що
вимагало публічного endpoint'а, — Telegram-кнопки тріажу, які викинуто. Mac
і так увімкнений наприкінці мітингу. VPS лишається для інших потоків
(invoices, voice-diary), але цей пайплайн його не чіпає.

### 2026-10-21 — v1 пише тільки в Obsidian
Власник (у сесії 2026-10-21): CRM (Directus `recordings`, матчинг з Google
Calendar) і Telegram-тріаж Work/Obsidian/Discard у v1 не переносяться. Усе
летить в Obsidian inbox з авто-заголовком; зайве видаляється руками. CRM —
можливий окремий крок пізніше.

### 2026-10-21 — Саммарі через Claude API
Власник: Claude API, за умови прийнятної ціни. Оцінка (ціни кешу 2026-10-06,
60-хв мітинг ≈ 15–20k вхідних токенів): Haiku 5.5 ≈ $0.003, Sonnet 5.5 ≈ $0.05,
Opus 5.5 ≈ $0.10 за мітинг. Модель — змінна `.env`; дефолт у плані Sonnet 5.5
(припущення автора плану, не рішення власника). Програли: DeepSeek (як зараз;
слабша укр. мова), локальна LLM (якість укр. мови, 1–3 хв на мітинг).
