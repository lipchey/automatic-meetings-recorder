# Документація — мапа

## Collections
- `plans/` — датовані плани робіт (`YYYY-MM-DD-slug.md`) + `roadmap/` (єдине джерело правди про прогрес).
- `specs/` — довговічні дизайн-документи й контракти; `specs/archive/` — єдина архівна папка.
- `research/` — датовані дослідження й базові зрізи (baseline) зовнішніх систем.
- `acceptance/` — датовані receipts: докази, що юніт плану виконано.

## Root documents
- `CONVENTIONS.md` — правила написання документів (де що живе, іменування, гейти).
- `../README.md` — публічний опис проєкту для GitHub/YouTube.
